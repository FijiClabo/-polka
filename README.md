# Полка

Telegram-бот и мини-приложение «Полка»: дочитай книгу за 30 дней — 15 минут чтения и минута пересказа в день,
с напарником, которого нельзя подвести.

Весь проект — в папке [`polka/`](polka/). Начни с [`polka/README.md`](polka/README.md):
там что сделано, что нужно для запуска и пошаговая инструкция по развёртыванию.
