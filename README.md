# Дочитка

Сервис в Telegram «Дочитка»: дочитай книгу за 30 дней — 15 минут чтения и минута пересказа в день,
с напарником, которого нельзя подвести. Бот, мини-приложение и лендинг; оплата — одной кнопкой «Оплатить»
через страницу ЮKassa, разово и без автопродления.

Весь проект — в папке [`dochitka/`](dochitka/). Начни с [`dochitka/README.md`](dochitka/README.md):
как сервис зарабатывает, что сделано, как подключить оплату, что нужно для запуска и пошаговая инструкция.
