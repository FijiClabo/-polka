# Запуск «Дочитки»: что подключить и одна команда

Как это устроено после запуска: один раз запускаешь скрипт на сервере — он ставит и настраивает всё сам.
Дальше любое изменение кода, отправленное в GitHub, проходит тесты и само выкладывается на сервер.
Руками остаются только регистрации и решения, которые за тебя никто не примет.

Подробности про продукт — [PRODUCT.md](PRODUCT.md), про пилот и клубы — [PILOT.md](PILOT.md).

## 1. Что подключить

| Что | Зачем | Где | Сколько | Что получить |
|---|---|---|---|---|
| Бот в Telegram | сам продукт | [@BotFather](https://t.me/BotFather) | бесплатно | токен бота (есть) |
| Твой Telegram ID | доступ в админку | [@userinfobot](https://t.me/userinfobot) | бесплатно | число, например 219… |
| GitHub | код и автообновление | github.com (есть) | бесплатно | три секрета — их выдаст скрипт |
| Сервер в России | бот, сайт, база | Timeweb Cloud (Москва) | 300–1 000 ₽/мес | IP и пароль root. Ubuntu 24.04; для теста хватит 1 ГБ, потом — 2 ГБ |
| Домен .ru | адрес сайта и мини-приложения | reg.ru, nic.ru, Timeweb | ~300 ₽/год | A-запись `app.домен.ru` → IP сервера |
| Yandex Cloud | ИИ-проверка пересказов и голос | console.yandex.cloud | на 20 человек: ~1–1,5 тыс. ₽/мес с моделью lite, ~4–5 тыс. с pro | API-ключ и ID каталога (ниже) |
| Релей за рубежом | связь бота с Telegram: с февраля 2026 Telegram в России замедляют, сильнее всего голосовые | самый дешёвый VPS в Нидерландах (например, FirstVDS) | несколько сотен ₽/мес | его домен `tg.домен.ru` (PILOT.md, шаг 6) |
| Самозанятость | законно брать деньги | приложение «Мой налог» | бесплатно | ФИО и ИНН для оферты |
| Уведомление в Роскомнадзор | бот хранит данные людей | pd.rkn.gov.ru | бесплатно | PILOT.md, шаг 3 |
| ЮKassa | оплата картой и СБП | yookassa.ru | % с платежа | позже: кнопка «Оплатить» уже есть |

**Supabase не нужен — и для этого проекта его нельзя.** Закон о персональных данных (ч. 5 ст. 18 152-ФЗ)
требует хранить базу с данными россиян на серверах в России, а у Supabase серверов в России нет. Бот всё равно
работает на своём сервере (Supabase не запускает Python-ботов), а база на том же сервере ничего не стоит,
бэкапится каждую ночь и не уезжает за границу.

### Yandex Cloud: ключ за 15 минут

1. [console.yandex.cloud](https://console.yandex.cloud) → создай платёжный аккаунт и пополни (новым часто дают грант).
2. Скопируй **ID каталога** — строка вида `b1g…` на главной странице каталога.
3. **Сервисные аккаунты → Создать**: имя `dochitka`, роли `ai.languageModels.user` и `ai.speechkit-stt.user`.
4. Открой аккаунт → **Создать новый ключ → API-ключ**. Секрет показывается один раз — сразу вставь его в скрипт.
5. **Billing → платёжный аккаунт → Бюджеты**: бюджет, например 1 500 ₽ в месяц, с письмами на 50, 90 и 100%.
   Жёстко остановить списания бюджет не может — это сигнал. Поэтому держи на балансе небольшую сумму
   и смотри расходы на ИИ в боте (`/sales`) или в **Админке**.

## 2. Запуск: одна команда

**Перед этим:** купи сервер и домен, в DNS домена добавь A-запись `app.твой-домен.ru` → IP сервера.

**Войди на сервер.** На Mac — приложение «Терминал», на Windows — PowerShell:

```bash
ssh root@IP_СЕРВЕРА
```

Пароль root придёт от хостинга. При вводе символы не видны — так и должно быть.

**Запусти установку:**

```bash
curl -fsSL https://raw.githubusercontent.com/FijiClabo/-polka/claude/telegram-book-app-ip11fm/dochitka/scripts/bootstrap.sh -o bootstrap.sh
bash bootstrap.sh
```

Скрипт задаст вопросы: домен, токен бота, твой Telegram ID, контакт поддержки, ключ Yandex Cloud, данные
продавца. Что пока неизвестно — пропускай Enter'ом и запускай скрипт ещё раз, когда появится: он ничего не ломает
и подставляет прошлые ответы. Первый запуск — 10–15 минут.

Что скрипт делает сам:

1. Обновляет систему, включает автообновления безопасности, защиту от подбора пароля (fail2ban), файрвол
   (открыты только SSH и сайт), подкачку.
2. Ставит Docker. Если Docker Hub из России недоступен — включает зеркала.
3. Скачивает код из GitHub в `/opt/dochitka`.
4. Записывает настройки в `/opt/dochitka/dochitka/.env` — доступ только у root. Пароль базы и секреты
   придумывает сам.
5. Проверяет, что домен смотрит на сервер, и подключает бота к Telegram — через релей, если он настроен.
6. Собирает и запускает бота, сайт и базу; HTTPS-сертификат получает сам.
7. Включает ежедневный бэкап базы.
8. Выдаёт ключ для автообновления из GitHub: он умеет только запускать обновление — ни консоли, ни туннелей.

## 3. Автообновление из GitHub

В конце скрипт покажет три значения. GitHub → репозиторий **FijiClabo/-polka** → **Settings → Secrets and
variables → Actions → New repository secret**, по одному:

| Имя секрета | Значение |
|---|---|
| `DEPLOY_HOST` | IP сервера |
| `DEPLOY_KNOWN_HOSTS` | строка `IP ssh-ed25519 AAAA…` из скрипта |
| `DEPLOY_SSH_KEY` | закрытый ключ целиком, от `-----BEGIN` до `END … KEY-----` |

С этого момента каждое изменение в ветке `claude/telegram-book-app-ip11fm` проходит тесты и само уезжает на
сервер (вкладка **Actions** в GitHub показывает, как прошло). Тесты упали — на сервер ничего не попадает.

## 4. После установки — руками (20 минут)

1. **Mini App в BotFather:** `/mybots` → бот → **Bot Settings → Configure Mini App → Enable Mini App** →
   `https://app.твой-домен.ru/app/`. Кнопка меню в чате бот ставит сам.
2. **Пройди путь сам** с двух аккаунтов: PILOT.md, шаг 9.
3. **Промокоды для тестеров:** мини-приложение → Профиль → Админка → Промокоды (PILOT.md, шаг 10).
4. **Самозанятость и Роскомнадзор** — до первых денег и первых людей (PILOT.md, шаги 2–3).

## 5. Оплата

Кнопка «Оплатить» уже есть в боте, в мини-приложении и на сайте («Оплатить 490 ₽», «Оплатить 3 990 ₽»).
Пока ЮKassa не подключена, она работает так:

1. Человек жмёт «Оплатить» — видит сумму и как заплатить (текст `PAYMENT_INFO` из `.env`; скрипт ставит
   «напиши @твой_контакт — пришлём реквизиты и чек») и кнопку «Написать».
2. Тебе в бот сразу приходит заявка: кто, какой тариф, сумма и готовая команда, например `/grant @olya run`.
3. Деньги пришли — отправляешь эту команду (или **Админка → Доступ**) и пробиваешь чек в «Мой налог».
   Человеку бот сам пишет, что доступ открыт.

Когда будешь подключать ЮKassa: на модерации проверяют сайт и бота — описание услуги, цены, оферту, контакты
и кнопку оплаты. Всё это уже есть на `https://app.твой-домен.ru/`. После договора впиши в `.env`
`YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY`, в кабинете ЮKassa укажи адрес уведомлений
`https://app.твой-домен.ru/pay/yookassa` и запусти `bash scripts/deploy.sh` — та же кнопка начнёт открывать оплату
картой и СБП.

## 6. Безопасность

**Что уже сделано в коде и на сервере** (проверено тестами, `tests/test_security.py`):

- вход в мини-приложение — только с подписью Telegram, подпись живёт сутки; без токена бота сервис не стартует,
  режим разработки (`DEV_AUTH_BYPASS`) на сервере не включается;
- адрес вебхука закрыт, пока бот работает без вебхука; команды администратора — только в личке с ботом
  и только с ID из `ADMIN_TG_IDS`;
- промокод — один раз на человека, подбор кодов перебором ограничен; бесплатный спринт нельзя растянуть;
- напарник по обычной ссылке не получает доступ к твоей книге; текст книги нельзя вытащить по кускам через
  смену темпа; отчёт для разбора — без имён, ников, ID, телефонов и почт;
- загрузки: книги проверяются на zip- и XML-бомбы, фото — на «фото-бомбы», метаданные и геометки фото удаляются;
  частота отзывов, фото и смены темпа ограничена;
- сервер: файрвол (открыты только SSH и сайт), защита от подбора пароля, автообновления безопасности,
  приложение в контейнере работает не от root, база и приложение не видны из интернета, HTTPS с HSTS,
  `.env` и бэкапы доступны только root, ключ GitHub умеет только запускать обновление.

**Что сделать тебе:**

- [ ] **Перевыпусти токен бота** перед запуском: @BotFather → `/mybots` → бот → **API Token → Revoke**. Старый
  токен ты присылал в чат — новый вставь только в скрипт на сервере.
- [ ] **Двухфакторный вход** на GitHub, в Yandex Cloud, у регистратора домена и у хостинга. Через них можно
  угнать сайт, бота или деньги.
- [ ] **SSH-ключ вместо пароля:** на своём компьютере `ssh-keygen -t ed25519`, затем
  `ssh-copy-id root@IP_СЕРВЕРА` (Windows: скопируй содержимое `~/.ssh/id_ed25519.pub` в
  `/root/.ssh/authorized_keys` на сервере), войди по ключу и запусти `bash bootstrap.sh` ещё раз — он выключит вход
  по паролю.
- [ ] **Бюджет с уведомлениями** в Yandex Cloud и небольшой баланс — жёсткого лимита там нет.
- [ ] **Копия бэкапов вне сервера** раз в неделю: `scp 'root@IP:/opt/dochitka/dochitka/backups/dochitka_*' .` — если
  сервер умрёт, данные останутся. Храни их как личные данные: в них отзывы участников и e-mail покупателей.
- [ ] **Админы** — только ты: в `ADMIN_TG_IDS` не добавляй тех, кому не доверяешь деньги и данные.
- [ ] Никому не пересылай `.env` и ключи из скрипта. Репозиторий открытый — секретов в нём нет и быть не должно.

## 7. Claude Code: как со мной работать дальше

- **Менять продукт** — здесь, в Claude Code на сайте claude.ai/code: я правлю код и отправляю в GitHub, а GitHub
  сам выкладывает на сервер. Сервер трогать не нужно.
- **Если что-то сломалось на сервере** — пришли мне вывод
  `cd /opt/dochitka/dochitka && docker compose logs --tail 200 app` и `docker compose exec app python -m scripts.doctor`.
- **Отчёт для разбора** — `/report` в боте, архив пришли мне.
- **Claude Code на своём компьютере** (если захочешь, чтобы он сам ходил на сервер по SSH): установка —
  `curl -fsSL https://claude.ai/install.sh | bash` (Mac) или `irm https://claude.ai/install.ps1 | iex`
  (Windows PowerShell), затем `claude` в папке проекта. Нужна подписка Pro или Max.
- **Важно:** по правилам Anthropic Россия не входит в список поддерживаемых стран
  ([anthropic.com/supported-countries](https://www.anthropic.com/supported-countries)), и правило касается того, где
  находится человек, а не сервер. Поэтому проверку пересказов в продукте делает YandexGPT, а не Claude.
