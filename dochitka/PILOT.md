# Пилот «Дочитки»: бесплатный запуск для 20–30 человек

Цель — за пару недель понять, дочитывают ли люди книги с сервисом и нравится ли им. Оплата и ИП пока не нужны:
доступ раздаём промокодом на 100%. Всё работает на Яндексе — без зарубежных сервисов и посредников.

**Бюджет на 2–3 недели — примерно 3–5 тыс. ₽**: сервер ~500–1000 ₽ в месяц, домен ~300 ₽, YandexGPT и SpeechKit
~2–4 тыс. ₽ (зависит от того, сколько человек читает каждый день).

---

## Шаг 1. Бот в Telegram (5 минут, бесплатно)

1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → имя (например, «Дочитка») и username
   (например, `dochitka_bot`). Сохрани **токен** — длинную строку вида `123456:AA...`.
2. Напиши [@userinfobot](https://t.me/userinfobot) — он пришлёт твой **ID** (число). Это ID администратора.

## Шаг 2. Yandex Cloud: ИИ и распознавание голоса (15 минут)

1. Зайди в [консоль Yandex Cloud](https://console.yandex.cloud), создай **платёжный аккаунт** и пополни его
   (новым аккаунтам часто дают стартовый грант — проверь в разделе «Биллинг»).
2. Открой каталог (его создают автоматически, обычно `default`). Скопируй **ID каталога** — строка вида
   `b1g...` в адресе или на странице каталога.
3. **Сервисные аккаунты → Создать**: имя `dochitka`, роли `ai.languageModels.user` и `ai.speechkit-stt.user`.
4. Открой сервисный аккаунт → **Создать новый ключ → API-ключ**. Сохрани **секретный ключ** — он показывается
   один раз.
5. В «Биллинге» поставь **лимит расходов** (например, 5000 ₽), чтобы не было сюрпризов.

## Шаг 3. Сервер и домен (20 минут)

1. Арендуй сервер в России: **Ubuntu 24.04, 2 ГБ памяти, 20 ГБ диска** (Timeweb, Selectel, Yandex Cloud и т. п.).
   Запиши **IP-адрес** и пароль root.
2. Купи домен (например, в `.ru`) и в настройках DNS добавь **A-запись** на IP сервера. Можно поддомен:
   `app.твой-домен.ru`. Запись начинает работать через 5–30 минут.

## Шаг 4. Запуск (15 минут)

Подключись к серверу (на Windows — через PowerShell, на Mac — Терминал):

```bash
ssh root@IP_СЕРВЕРА
git clone https://github.com/FijiClabo/-polka.git dochitka-repo
cd dochitka-repo/dochitka
sudo bash scripts/server_setup.sh
nano .env
```

В открывшемся файле заполни эти строки (остальное не трогай). Сохранить — Ctrl+O, Enter, выйти — Ctrl+X.

```ini
DOMAIN=app.твой-домен.ru
PUBLIC_URL=https://app.твой-домен.ru
BOT_TOKEN=123456:AA...            # из шага 1
ADMIN_TG_IDS=123456789            # твой ID из шага 1
SUPPORT_CONTACT=@твой_username    # куда писать участникам

LLM_PROVIDERS=yandex              # только Яндекс
YANDEX_API_KEY=AQVN...            # секретный ключ из шага 2
YANDEX_FOLDER_ID=b1g...           # ID каталога из шага 2
STT_PROVIDER=yandex

SELLER_NAME=Иванов Иван Иванович  # кто отвечает за данные (оператор) — нужно для политики и согласия
SELLER_STATUS=физическое лицо
SELLER_INN=123456789012           # твой ИНН (узнать можно на nalog.ru)
SELLER_EMAIL=you@example.com
PAYMENT_INFO=Сейчас идёт бесплатный тест по приглашениям.
```

Запусти:

```bash
bash scripts/deploy.sh
```

В конце скрипт проверит настройки. Строки `[ок]` — хорошо, `[совет]` — можно поправить потом, `[ошибка]` — нужно
исправить (под строкой написано как) и снова запустить `bash scripts/deploy.sh`. Строки про ЮKassa и реквизиты
ИП на время пилота можно пропустить.

Проверь: `https://app.твой-домен.ru/` открывает сайт, а бот отвечает на `/start`.

## Шаг 5. Мини-приложение в BotFather (2 минуты)

[@BotFather](https://t.me/BotFather) → `/mybots` → твой бот → **Bot Settings → Configure Mini App → Enable
Mini App** → адрес `https://app.твой-домен.ru/app/`. Кнопку в меню чата бот настраивает сам.

## Шаг 6. Пройди путь сам (20 минут)

1. `/start` → приветствие → «Даю согласие» → пояс и время → пробный пересказ.
2. Добавь книгу: пришли файл epub или fb2 или выбери «бумажную».
3. Выбери срок. Бот покажет тарифы — выдай себе доступ: `/grant @твой_username month`.
4. Открой мини-приложение, перескажи отрезок голосом и текстом, загляни в «Друзья» и «Полку».
5. Проверь ИИ на трудных сценах (насилие, война, любовная сцена): на сервере
   `docker compose exec app python -m scripts.ai_eval --sensitive`. Если много строк «error» — фильтры
   Яндекса срабатывают часто; напиши мне, подстроим.

## Шаг 7. Приглашаем тестеров

Создай промокод **только на месяц** на 30 человек (код — латиницей):

```
/promo_new PILOT 100 30 month
```

Бот ответит ссылкой вида `t.me/dochitka_bot?start=promo_PILOT` — её и рассылай. Человек переходит по ссылке,
проходит знакомство, добавляет книгу, выбирает срок и жмёт «Месяц по промокоду — бесплатно» (в мини-приложении —
«Подключить по промокоду»).

Удобно написать вместе со ссылкой: «Это тест: 15 минут чтения в день и короткий пересказ. Месяц бесплатно.
Пиши мне, если что-то непонятно или сломалось».

## Шаг 8. Что смотреть во время пилота

- `/sales` — воронка: сколько нажали `/start`, добавили книгу, выбрали план, сдали первый день, дочитали.
- `/user @username` — где человек, сколько дней сдал, какие были вердикты.
- `/broadcast текст` — сообщение всем участникам (например, «как вам первая неделя?»).
- Расходы — в консоли Yandex Cloud, раздел «Биллинг»: раздели сумму на число активных читателей.

Главные вопросы пилота: **сколько человек сдают дни хотя бы неделю** и **сколько дочитывают книгу**.

## Через 2–3 недели: включаем оплату для новых людей

1. Оформи самозанятость или ИП, заключи договор с ЮKassa.
2. Впиши в `.env` ключи `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY`, реквизиты `SELLER_*` и цены
   (`PRICE_MONTH_RUB` и др.), в кабинете ЮKassa — адрес уведомлений `https://ДОМЕН/pay/yookassa`.
3. Отключи пилотный код: `/promo_off PILOT`. Запусти `bash scripts/deploy.sh`.

Подробно про оплату, команды и устройство — в [README.md](README.md).
