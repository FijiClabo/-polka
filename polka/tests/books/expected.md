# Тестовый набор книг (раздел 9.8 ТЗ)

Реальные файлы в репозиторий **не коммитятся**. Есть два набора:

1. **Синтетический** — генерируется кодом (`books/samples.py`), проверяется автоматически в `tests/test_books.py`.
   Сохранить файлы на диск для ручной проверки бота: `python -m scripts.make_samples ./samples`.
2. **Реальный** — 8–10 настоящих файлов от автора проекта. Положить в `tests/books/files/` (папка в `.gitignore`)
   и прогнать: `python -m scripts.check_book tests/books/files/*` — скрипт печатает результат по каждому файлу.

| # | Файл | Ожидаемый результат |
|---|------|---------------------|
| 1 | Аккуратный epub с оглавлением | `ok`: главы по оглавлению, обложка/выходные данные/«об авторе»/реклама отброшены, сноски убраны |
| 2 | epub без оглавления | `ok`: главы по заголовкам h1/h2 |
| 3 | epub с одной гигантской главой | `ok`: деления на главы нет, отрезки по абзацам, названия «День 1», «День 2»… |
| 4 | fb2 (windows-1251, части и главы, примечания) | `ok`: «Часть 1. Глава 1», примечания (`body name="notes"`) отброшены |
| 5 | fb2.zip | `ok`: так же, как fb2 |
| 6 | epub с защитой (encryption.xml, Adobe DRM) | `failed: drm` → «Файл защищён от копирования…» + предложение бумажного режима |
| 7 | Книга из картинок (скан) | `failed: no_text` → «похоже, книга состоит из картинок» |
| 8 | Очень короткая (меньше 20 стр.) | `failed: too_short` |
| 8а | Короткая (20–62 стр.) | `ok`: сроки 7 или 14 дней |
| 9 | Очень длинная (больше 1200 стр.) | `ok`: только 60 дней с предупреждением о нагрузке |
| 10 | epub2 c NCX, все главы в одном файле с якорями | `ok`: главы режутся по якорям внутри файла |

Дополнительно проверяется: обфускация шрифтов в encryption.xml **не** считается защитой;
XML-бомба (сущности) и zip-бомба отклоняются; битый файл → `broken`.
